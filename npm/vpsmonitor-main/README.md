# @sunjiehao/vpsmonitor-main

Main VPS installer and manager for VPSMonitor.

```bash
npm i -g @sunjiehao/vpsmonitor-main
vpsmonitor-main install
vpsmonitor-main add-sub
vpsmonitor-main nodes
```

The installer prompts for settings and installs both the controller and a local agent for monitoring the main VPS itself.
